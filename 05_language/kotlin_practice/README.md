## Kotlin 기본 구조

```kotlin
fun main() {
    println("Hello world!")
} // Hello world!
```
`fun`: 함수 선언에 사용된다.  

`main()`: **main** 이름을 가진 함수는 해당 프로그램의 시작점을 의미한다.  

`{}`: 함수의 구현부는 중괄호 내에 정의된다.

`println()`: 해당 함수는 매개변수를 표준 출력으로 내보내는 함수다.

해당 구조를 통해 기본적인 실행 가능한 프로그램을 작성할 수 있다.
